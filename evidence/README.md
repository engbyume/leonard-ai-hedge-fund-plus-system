# Evidence layer

This directory contains the public, redacted evidence for the personal experiment. It is not a live portfolio feed.

- [`progress.md`](progress.md) explains what is known, what is inferred, and what remains unproven.
- [`weekly-checkpoints.csv`](weekly-checkpoints.csv) contains percentage returns and benchmark spreads only.
- [`decision-log.md`](decision-log.md) records system advice, the operator's choice, rule changes, and verification.
- [`source-register.md`](source-register.md) maps claims to source types and freshness.

The latest percentage comparison in this publication is from the August 10, 2026 report, using market closes through August 7. It is an open-position comparison with incomplete cost and cash-flow evidence, not a verified July 11 trial-start result. A user confirmation on August 8 records a separate personal state update; it is not a performance observation.
